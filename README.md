# Dnevnik
# Ахмедов Файзулло Шавкатжанович

## Суть приложения
Мобильное приложение «Мои Задачи» — это удобный и стильный менеджер задач (To-Do List). 
Приложение позволяет пользователю:
* Создавать новые задачи с заголовком и описанием.
* Редактировать существующие задачи.
* Отмечать задачи как выполненные (с визуальным зачеркиванием текста).
* Удалять ненужные задачи.
* Фильтровать задачи (показывать все или только выполненные).
* Отслеживать статистику выполнения задач в реальном времени на главном экране.


## Технологический стек
* **Язык разработки:** Dart
* **Фреймворк:** Flutter
* **Стейт-менеджмент:** Provider (пакет `provider`)
* **Платформа:** Android / iOS
